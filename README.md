# Xi Fang Personal Website

Source for the personal website of Xi Fang.

- Website: `https://xifang001.github.io/`
- Framework: `Hugo`
- Deployment: `GitHub Pages`

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Main Sections

- Home
- Projects
- Publications
- News
- Blog
- Awards & Honors

## Structure

- Content: `content/`
- Layouts: `layouts/`
- Styling: `static/css/site.css`
